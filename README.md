# Rakesh Sivakumar — Portfolio

A responsive personal portfolio website for Rakesh Sivakumar.

## Technologies used
- HTML5
- CSS3 (responsive layout and styling)
- Vanilla JavaScript

## Run locally
1. Download and extract the project ZIP.
2. Open the `rakesh-portfolio` folder.
3. Open `index.html` in a browser. No build step is required.

## Deploy with Vercel
1. Create a GitHub repository and upload all files in this folder.
2. In Vercel, choose **Add New → Project** and import that GitHub repository.
3. Keep Framework Preset as **Other**. No build command or output directory is required.
4. Click **Deploy**.
